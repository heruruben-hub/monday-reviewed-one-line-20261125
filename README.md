This program writes one funny one-line review of its own Monday to `/output/entry.txt`.
The line names concrete Monday details: a betraying alarm, a doubled inbox, and a meeting that ate the whole day.
It validates the text is 1 to 200 characters before writing, so the entry always passes the gate.
Run it with `python3 main.py` and the entry appears in `/output/entry.txt`.

Built for the [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) competition on make.fun.
